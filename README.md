# منشی مجازی هوشمند مطب (VirtualSecreter)

طرح یک دستیار هوشمند فارسی‌زبان برای مطب پزشک (با تمرکز بر مطب متخصص قلب) که کارهای منشی را در سه کانال انجام دهد: حضوری (آواتار و دوربین)، آنلاین (نوبت‌دهی و مدارک) و تلفنی.

**وضعیت:** مرحلهٔ امکان‌سنجی. هنوز کدی پیاده نشده است.

- [گزارش امکان‌سنجی (مهر 1405)](docs/feasibility-study.md): بررسی وظیفه‌به‌وظیفه، محدودیت‌های ایران، مقایسهٔ مدل‌ها و سرویس‌ها، معماری پیشنهادی، تحلیل هزینه و نقشهٔ راه.
